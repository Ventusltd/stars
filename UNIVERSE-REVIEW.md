# Complete numbered-code universe

Use the normalized builder for publication:

```
node modular-star/universe-compact.mjs <modular.sqlite> <stars-source-directory> <new-output-directory> <exact-source-commit>
node modular-star/universe-compact-proof.mjs <output-directory>
```

Place the generated directory at `data/` beside the files in `modular-star/universe-viewer/`. The viewer is a read-only relational graph with accessible buttons, permanent-key navigation, complete paginated relationship lists and checksum-verified line text. Full-commit source links open the recorded GitHub file. It does not execute builds, edit code or infer runtime dependency proof.
